# Support

- **Bugs / features:** GitHub Issues (bug-report / feature-request forms).
- **Questions:** GitHub Discussions (Q&A). Please include `bat2ps doctor`
  output and a minimal `.bat` repro.
- **Response expectations:** best effort by volunteers; issues triaged
  weekly, security reports per `SECURITY.md`.
- **Supported platform:** Windows 10/11 + Server 2022 with
  `cmd.exe` and PowerShell 5.1+, Python 3.10–3.12.
